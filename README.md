**# Library Management System**

**## 1. Project Title**

**\*\*Library Management System\*\***

**## 2. Overview of the Project**

The Library Management System is a simple Python-based console application used to manage books in a library.

The program allows the user to add books, issue books, return books, and view all the books currently available in the library. The books are stored using a Python list.

This project demonstrates the use of **\*\*lists, functions, conditional statements, loops, user input, and basic Python operations\*\***.

**## 3. Features**

The main features of the project are:

\- **\*\*Add Book\*\*** – Adds a new book to the library.

\- **\*\*Issue Book\*\*** – Issues a book if it is available in the library.

\- **\*\*Return Book\*\*** – Adds a returned book back to the library.

\- **\*\*View Books\*\*** – Displays all books currently available.

\- **\*\*Exit\*\*** – Closes the Library Management System.

\- **\*\*Invalid Choice Handling\*\*** – Displays an error message when an invalid menu option is entered.

**## 4. Technologies/Tools Used**

\- **\*\*Programming Language:\*\*** Python

\- **\*\*Data Structure:\*\*** List

\- **\*\*Interface:\*\*** Console/Command Line

\- **\*\*Editor/IDE:\*\*** VS Code, IDLE, PyCharm, or any Python-supported editor

\- **\*\*Python Version:\*\*** Python 3.x
