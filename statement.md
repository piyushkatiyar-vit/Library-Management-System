**# Library Management System – Project Statement**

**## 1. Problem Statement**

It might get too complicated to keep track of all the books in a library, especially about the ones issued and returned. Thus, creating a program that could keep a track of all the available, issued, and returned books would make things a lot easier. The Library Management System is a basic Python console application that keeps a track of the books in a library. It provides the user with multiple functions including adding a book, issuing a book, returning a book, and viewing the current list of available books. The application uses a basic Python list to store the books and functions to carry out the aforementioned operations.

**## 2. Scope of the Project**

The scope of the project is to create a basic library management system that provides fundamental operations such as adding books, issuing books, returning books, viewing the books, handling invalid inputs, and a console interface.

The system will have the following operations:

1\. Adding a book to the library.

2\. Issuing a book from the library.

3\. Returning a book to the library.

4\. Viewing the current list of books in the library.

5\. Handling invalid user input.

6\. Console interface to interact with the system.

The project scope does not include advanced features such as a relational database to store the data, user account management, login and authentication system, and fine management system.

**## 3. Target Users**

The target users of the Library Management System are as follows:

1\. Students: The console application can be used by students as a sample Python application.

2\. Teachers: The console application can be used by teachers to demonstrate basic Python concepts.

3\. Small Libraries: The system can be used in a library to manage the books in the library.

4\. Librarians: The system can also be used by the librarian to carry out book management in the library.

**## 4. High-Level Features**

1\. Add Book: The feature allows the user to add the book to the library by providing the book’s name.

2\. Issue Book: The feature allows the user to issue the book from the library. It will remove the book from the available books list in the library.

3\. Return Book: The feature allows the user to return the book to the library. It will add the book to the available books list in the library.

4\. View Books: The feature allows the user to view all the current available books in the library in a list format. If there are no books in the library, it will prompt the user that no books were found.

5\. Exit: The feature allows the user to exit the console application.

6\. Invalid Choice Handling: The feature handles invalid user input and prompts them with a suitable message.
